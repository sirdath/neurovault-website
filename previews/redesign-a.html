Local-first, actually

The engine binds to loopback only and refuses outside connections. Not "encrypted in transit", not "we do not train on it". The network path does not exist.

BGE-small ONNX

Zero-LLM ingest

On-device embeddings only. No API key, no cloud call, no token bill. Privacy is structural, not a policy page.

Plain .md files

Markdown is canonical

Your brain is a folder of markdown. 10,000 notes weigh about 130 MB, the database is a rebuildable index, and Obsidian opens it as-is.

05Multi-agent

One shared brain. Many agents.

An agent finishes a task, writes a handoff, and walks away. The next agent opens its inbox and picks the work up, hours or machines apart.

handoff routes a directed, inert message to another agent. agent_inbox reads the open handoffs addressed to you. session_start(agent=X) scopes wake-up to X's own recent memory plus X's inbox. NeuroVault is a coordination substrate, not an orchestrator: nothing auto-runs, nothing gets scheduled. And every recalled fact carries a 0 to 1 confidence signal, computed on-device with zero LLM calls.
